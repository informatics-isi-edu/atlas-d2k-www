## Abstract
This protocol describes methods used by the Editorial Office in the University of Edinburgh for checking annotations in GUDMAP1, GUDMAP2 and nGUDMAP.

## Procedure
The Annotation Tool is a graphical interface that allows users to add expression strengths, patterns/locations, and notes to their submissions.  These temporary submissions will contain all annotation data but not metadata such as probe details, submitter details etc which are to be submitted using the submission spreadsheet. For submissions sent using the Annotation Tool the EO perform the following checks:

- Check that the temporary GUDMAP IDs match those in the submitted spreadsheet.
- Check the sex of the specimen and if necessary revise the online annotation.
- Check the Theiler stage to ensure that it matches that specified in the submitted spreadsheet.
- In addition the EO checks the accompanying spreadsheet.
